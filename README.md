# CyberLoss - КТ4, команда KIB-47

**Автор и капитан:** Рогачев Максим Андреевич  
**Дата промежуточной версии:** 24.11.2026  
**Статус:** рабочий учебный прототип (версия 0.1), для промежуточного просмотра КТ4

## 1. Проблема и пользователь

Владелец малого интернет-магазина не всегда может быстро перевести киберриск в понятную денежную оценку. При остановке сайта, системы заказов или связанных сервисов вследствие киберинцидента возникают потерянные продажи и затраты на восстановление. Пользователь прототипа - владелец или управляющий малого интернет-магазина.

**Цель MVP:** по введённым синтетическим показателям оценить финансовые последствия простоя и сравнить несколько вариантов длительности остановки.

## 2. Как запустить (ничего устанавливать не нужно)

1. Скачайте `CyberLoss_KIB47.html` на компьютер.
2. Откройте файл двойным щелчком в любом современном браузере (Chrome, Edge, Firefox).
3. Измените параметры сценария и нажмите «Рассчитать ущерб».
4. Сравните результаты для 12, 24, 48 и 72 часов. Кнопка «Тестовый пример» возвращает учебные значения.
5. Кнопка «Распечатать / PDF» позволяет сохранить результат через системную печать браузера.

Приложение работает **без интернета, учётной записи и сервера**. Данные никуда не отправляются.

## 3. Выполненные функции КТ4

- Ввод дневной выручки, маржинальности, длительности простоя, доли затронутых продаж, доли невосстановленных заказов, расходов на восстановление и реагирование.
- Расчёт выручки под риском, безвозвратно потерянной выручки, упущенного маржинального дохода, прямых затрат и итогового условного ущерба.
- Автоматический пересчёт при изменении вводимых данных.
- Сравнение четырёх длительностей простоя с визуализацией.
- Проверка вводимых значений, пример тестовых данных, печать и копирование результатов.

## 4. Формула и допущения

```
Выручка под риском = выручка в день * часы простоя / 24 * доля остановленных продаж / 100
Невосстановленная выручка = выручка под риском * доля невосстановленных заказов / 100
Упущенный маржинальный доход = невосстановленная выручка * маржинальность / 100
Прямые расходы = восстановление + реагирование
Итоговый ущерб = упущенный маржинальный доход + прямые расходы
```

Результат - **сценарная учебная оценка**, не страховой прогноз. Маржинальность понимается как доля вклада в покрытие постоянных расходов и прибыль. Нельзя одновременно прибавлять к потерянному доходу весь оборот - это привело бы к двойному счёту. Не учитываются отток клиентов, сезонность, штрафы, упущенные маркетинговые возможности и репутационные потери.

## 5. Воспроизводимое демо и тестирование

Нажмите «Тестовый пример» и проверьте параметры:

| Параметр | Значение |
| --- | ---: |
| Дневная выручка | 120 000 ₽ |
| Маржинальность | 30% |
| Простой | 48 ч |
| Остановленные продажи | 100% |
| Невосстановленные заказы | 80% |
| Восстановление | 45 000 ₽ |
| Реагирование | 20 000 ₽ |

**Ожидаемый результат:** выручка под риском 240 000 ₽, потерянная выручка 192 000 ₽, упущенный маржинальный доход 57 600 ₽, прямые расходы 65 000 ₽, итог **122 600 ₽**.

Проверки граничных ситуаций: при нулевом простое и нулевых прямых расходах результат 0 ₽; при 0% затронутых продаж упущенный маржинальный доход 0 ₽; отрицательные числа и проценты больше 100% не принимаются.

## 6. Безопасность и ограничения

Клиентское автономное приложение не запрашивает персональные данные, не делает сетевые запросы и не взаимодействует с реальными информационными системами. Все данные - условные. Полноценная рыночная проверка, исследование аналогов, демонстрационное видео, презентация и окончательная документация относятся к следующему этапу и в версии КТ4 ещё не заявляются готовыми.
